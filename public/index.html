Static JSON API

食品成分表示API

文部科学省「日本食品標準成分表（八訂）増補2023年」を元にした、食品の成分値を返す静的JSON API。認証不要・無料で利用できます。

食品を検索 ドキュメント 利用規約 プライバシーポリシー 連絡先・運営会社

ドキュメント

エンドポイント

パス内容
/index.json全食品の食品番号・食品名などの一覧
/data/{食品番号}.json1食品ごとの成分データ（例: /data/01001.json）
/metadata.json成分識別子の和名・単位、食品群コード表、値注記の凡例
/llms.txtLLM／エージェント向けの利用ガイド

使い方

  1. /index.json を取得し、食品名などから目的の食品の code（食品番号、5桁）を特定する。
  2. /data/{code}.json を取得し、成分データを得る。
  3. 各成分の識別子（WATER, ENERC など）の意味・単位は /metadata.json の identifiers を参照する。
curl https://food-ingredients.pons-llc.com/index.json
curl https://food-ingredients.pons-llc.com/data/01001.json

値の読み方

各成分値は次の形のオブジェクトです。

{ "raw": "(11.3)", "value": 11.3, "estimated": true, "trace": false, "unmeasured": false }
フィールド意味
rawExcel原本のセルの値をそのまま保持したもの
value数値化できた場合の数値。Tr・-・空欄などは null
estimatedtrue なら推計値（原本で (数値) と表記）
tracetrue なら微量（Tr）
unmeasuredtrue なら未測定（-）
